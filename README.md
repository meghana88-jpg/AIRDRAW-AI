
# AirDraw AI 🎨

AirDraw AI is a real-time virtual drawing application that allows users to draw in the air using hand gestures.

## Features

- Real-time hand tracking using MediaPipe
- Draw using your index finger
- Move using two fingers
- Erase using a closed fist
- Smooth drawing experience
- Undo previous strokes
- Clear the canvas
- Save drawings as PNG images

## Technologies Used

- HTML
- CSS
- JavaScript
- MediaPipe Hand Landmarker

## How to Run

1. Download or clone this repository.
2. Open the project in Visual Studio Code.
3. Install the Live Server extension.
4. Open index.html with Live Server.
5. Click Start Camera.
6. Allow camera permission.

## Gestures

| Gesture | Action |
|---|---|
| Index finger | Draw |
| Two fingers | Move |
| Closed fist | Erase |
